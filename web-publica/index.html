PREGUNTAS FRECUENTES

Antes de reservar

¿Cuándo queda confirmada mi reserva?

La solicitud queda confirmada cuando el complejo acredita la seña y el estado cambia a CONFIRMADA.

¿Qué pasa si vence el plazo de la seña?

La solicitud expira y el horario vuelve a quedar disponible para otra reserva.

¿Cómo informo el pago?

Después de crear la solicitud, podés usar el botón de WhatsApp y enviar los datos del pago junto con el número de solicitud.

¿Dónde consulto el estado?

Usá Ver reserva o Mis reservas. También podés ingresar el código de seguimiento recibido al finalizar la solicitud.

¿Puedo modificar o cancelar el turno?

Para solicitar un cambio o una cancelación, comunicate directamente con el complejo por WhatsApp.

¿Qué datos se guardan en este dispositivo?

El historial y los datos que elijas recordar se guardan solamente en este navegador. El documento no se recuerda automáticamente.
